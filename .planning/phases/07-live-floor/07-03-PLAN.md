After Wave 3:
- Navigating to `/floor` (or `/floor?status=STALE`) renders the live map with the right initial filter
- The pill bar shows the three counters with live counts, built from a single PILLS array (NIT1)
- The Order-rejection pill has a tooltip noting the Keeta-only v1 limitation (W3 documentation)
- Clicking a pill filters the map AND opens a list overlay (resolution #2)
- The filter bar lets the dispatcher narrow by platform/area/search; state syncs to the URL (resolution #6)
- Clicking a marker (or a list row) opens the right-rail panel — the panel and the overlay are mutually exclusive (W5: never both at once)
- The panel reuses existing Phase 2/3/4 primitives: SlidePanel, DriverLink, AskDarbWhyDrawer (with the correct `{text, cached}` preWarmed shape per B4), ChatActionCard
- Every dynamic platform styling reads from `PLATFORM_BG` / `PLATFORM_TINT` / `PLATFORM_RING` in `@/types/floor` (B3 — Tailwind JIT-friendly)
- Clicking the Ping button stages a PendingAgentAction via the Wave 1 route and renders the ChatActionCard
- Approving the ChatActionCard hits the existing `/api/decisions/:id/approve` (Phase 2) → Notification row created
- The "real WhatsApp send" is deferred to Phase 9 (resolution #3) — v1 only stages the IN_APP/notification draft; the button label reflects this ("Send via Darb" per resolution #5)

Seven deliverables:

1. **`frontend/src/app/(dashboard)/floor/page.tsx` (NEW)** — server-component shell. Inherits the dashboard layout's auth check (existing pattern from `/decisions/page.tsx`). Dynamic-imports `<LiveFloorPage/>` with `ssr: false` (Pitfall 3: react-leaflet calls `window` at module import time).

2. **`<LiveFloorPage/>` (NEW)** — top-level `"use client"` orchestrator. Composes:
   - `useFloorRealtime()` hook (Wave 2)
   - `useState` for `filter: FloorFilter`, `selectedDriverId: string | null`, `listOpen: boolean`
   - **Mutual-exclusion guard (W5):** wraps `setSelectedDriverId` and `setListOpen` so they cannot both be active. Selecting a driver auto-closes the overlay; opening the overlay clears the selected driver. The render branch is a single XOR: `selectedCourier ? <CourierDetailPanel/> : listOpen ? <FloorListOverlay/> : null` — when `selectedDriverId !== null`, render only `<CourierDetailPanel/>`; otherwise when `listOpen`, render only `<FloorListOverlay/>`.
   - Reads initial filter from `useSearchParams` on mount
   - Computes `filteredCouriers` client-side from `couriers` + `filter`
   - Renders: header → `<FloorPillCounters/>` → `<FloorFilters/>` → dynamic `<LiveFloorMap/>` (ssr:false) → `<CourierDetailPanel/>` XOR `<FloorListOverlay/>`

3. **`<FloorPillCounters/>` (NEW)** — 3 clickable pills built from a SINGLE `PILLS` array with explicit status field per pill (NIT1). The PILLS array has one entry per `FloorCounters` key (scheduledNotOnline / gpsStale / orderRejection). The Order-rejection pill carries a `title` attribute reading `"v1: Keeta only. Cross-platform signal ships in Phase 10."` (W3). Click handler emits `onPillClick(status)` to parent; parent maps to BOTH `onFilterChange({status})` AND `onListOpen()` — resolution #2. Active pill has `aria-pressed=true` + `bg-primary` styling; zero-count pill is dimmed.

4. **`<FloorFilters/>` (NEW)** — three controls:
   - Platform multi-select (4 chips: KEETA/TALABAT/DELIVEROO/AMERICANA, click toggles); chip background reads from `PLATFORM_BG[platform]` (B3 — static map)
   - Area dropdown (populated from current couriers' area set + a "(all)" option)
   - Search input (debounced 200ms)
   - All three controls sync to URLSearchParams via `useRouter().replace()` (does NOT add a history entry per keystroke — resolution #6 + UX: use `router.replace` not `router.push`)

5. **`<CourierDetailPanel/>` (NEW)** — right-rail panel for the selected courier. Composition per resolution #5:
   - Wraps `<SlidePanel/>` (Phase 2)
   - Header: `<DriverLink/>` (Phase 3) + platform tag (uses `PLATFORM_TINT[platform]` per B3) + status chip
   - Score chip: small variant of Phase 3's score visual (just the numeric score + trend arrow; the full ScoreTrendChart is too heavy)
   - Last 5 `OrderEvent` rows: `GET /api/drivers/:id/file` (Phase 3 endpoint) returns the trailing events
   - `<AskDarbWhyDrawer/>` (Phase 3) — preWarmed prop constructed as `{ text: STATUS_REASON[status], cached: false } satisfies DriverFileScoreExplanation` (B4: matches the existing `{text, cached}` contract from `frontend/src/types/driver-file.ts:34`; NO `as any` cast and NO synthetic `{signal, reasoning, suggestedActions}` shape)
   - `<PingButton/>` (Wave 3)
   - The panel's `open` state is the existence of `selectedDriverId`; `onClose` clears it in the parent (no map state lost)

6. **`<PingButton/>` (NEW)** — the propose-and-confirm wrapper. UX flow:
   - Initial: button with "Send via Darb" label (resolution #5) — clicking triggers an inline draft preview
   - Clicked: POST `/api/floor/ping/:driverId` with `{intent, bodyEnglish: <agent draft>}`
   - On `{pendingActionId, requiresApproval: true}` response: render `<ChatActionCard proposal={{pendingActionId, subject: 'Ping driver', body: bodyEnglish, ctaLabel: 'Send via Darb'}}/>` — the existing card's default `onApprove` hits `/api/decisions/:id/approve` (Phase 2)
   - The draft body is built inline based on `intent` (e.g., for `WARN_GPS_STALE`: "Hi {name}, your GPS hasn't updated in 15 min. Could you check your app/location settings? — Darb").
   - On error: small inline message; button re-enabled.

7. **`<FloorListOverlay/>` (NEW)** — slide-in list of the filtered drivers when a pill is clicked. Each row: driver name + platform chip (uses `PLATFORM_TINT[platform]` per B3) + status. Clicking a row sets `selectedDriverId` (which opens the panel AND auto-closes the overlay via the parent's mutual-exclusion wiring per W5).

Output: 7 new files (~520 lines total). Zero new npm packages. Zero schema or backend changes — Wave 3 only consumes the Wave 1 API + Wave 2 hook/map.

// Phase 7 Wave 3 — top-level orchestrator for the Live Floor surface.
// W5: CourierDetailPanel and FloorListOverlay are MUTUALLY EXCLUSIVE.
// Wrapper setters guarantee they never render simultaneously.
"use client";
import { useState, useMemo, useEffect, useCallback } from "react";
import dynamic from "next/dynamic";
import { useSearchParams } from "next/navigation";
import { useFloorRealtime } from "@/hooks/useFloorRealtime";
import { FloorPillCounters } from "./FloorPillCounters";
import { FloorFilters } from "./FloorFilters";
import { CourierDetailPanel } from "./CourierDetailPanel";
import { FloorListOverlay } from "./FloorListOverlay";
import { classifyCourier } from "@/types/floor";
import type { FloorFilter, CourierStatus } from "@/types/floor";

// LiveFloorMap is also dynamic-imported here so any ad-hoc consumer using
// <LiveFloorPage/> in a Storybook (or tests with module-mocked react-leaflet)
// can still render the shell without booting Leaflet.
const LiveFloorMap = dynamic(
  () => import("./LiveFloorMap").then((m) => m.LiveFloorMap),
  { ssr: false, loading: () => <div className="h-full w-full bg-sand-50" /> },
);

function hydrateInitialFilter(params: URLSearchParams): FloorFilter {
  const platforms = (params.get("platforms")?.split(",").filter(Boolean) as FloorFilter["platforms"]) ?? undefined;
  const area = params.get("area") ?? undefined;
  const q = params.get("q") ?? undefined;
  const status = (params.get("status") as CourierStatus | null) ?? undefined;
  return { status, platforms, area, q };
}

export function LiveFloorPage() {
  const searchParams = useSearchParams();
  const [filter, setFilter] = useState<FloorFilter>(() => hydrateInitialFilter(new URLSearchParams(searchParams?.toString() ?? "")));
  const [selectedDriverId, _setSelectedDriverId] = useState<string | null>(null);
  const [listOpen, _setListOpen] = useState(false);
  const { couriers, counters, connected } = useFloorRealtime();

  // W5: Mutual exclusion. Selecting a driver auto-closes the overlay.
  //     Opening the overlay clears the selected driver.
  //     Render branch is XOR: selectedCourier ? Panel : listOpen ? Overlay : null
  //     so the two components NEVER render simultaneously regardless of any
  //     z-index drift in their underlying SlidePanel-style containers.
  const setSelectedDriverId = useCallback((id: string | null) => {
    _setSelectedDriverId(id);
    if (id !== null) _setListOpen(false);
  }, []);

  const setListOpen = useCallback((open: boolean) => {
    _setListOpen(open);
    if (open) _setSelectedDriverId(null);
  }, []);

  // Re-hydrate when the URL changes (browser back/forward or external link).
  useEffect(() => {
    setFilter(hydrateInitialFilter(new URLSearchParams(searchParams?.toString() ?? "")));
  }, [searchParams]);

  const filtered = useMemo(() => {
    const nowMs = Date.now();
    return couriers.filter((c) => {
      if (filter.platforms && filter.platforms.length > 0 && (!c.platform || !filter.platforms.includes(c.platform))) {
        return false;
      }
      if (filter.area && c.area !== filter.area) return false;
      if (filter.q) {
        const q = filter.q.toLowerCase();
        if (!c.name.toLowerCase().includes(q) && !(c.phone ?? "").includes(q)) return false;
      }
      if (filter.status) {
        const status = classifyCourier(c, nowMs);
        if (status !== filter.status) return false;
      }
      return true;
    });
  }, [couriers, filter]);

  const handlePillClick = (status: CourierStatus) => {
    setFilter((prev) => ({ ...prev, status }));
    setListOpen(true);   // W5: this also clears selectedDriverId
  };

  const selectedCourier = useMemo(
    () => couriers.find((c) => c.driverId === selectedDriverId) ?? null,
    [couriers, selectedDriverId],
  );

  return (
    <div className="flex flex-col h-full">
      <div className="border-b border-sand-200 px-6 py-3 flex items-center justify-between bg-card">
        <div>
          <h1 className="font-display text-display-sm text-sand-900">Live Floor</h1>
          <p className="text-xs text-sand-500">
            {connected ? "Connected" : "Reconnecting…"} · {filtered.length} of {couriers.length} couriers
          </p>
        </div>
        <FloorPillCounters
          counters={counters}
          activeStatus={filter.status}
          onPillClick={handlePillClick}
        />
      </div>
      <FloorFilters
        filter={filter}
        couriers={couriers}
        onChange={setFilter}
      />
      <div className="flex-1 relative">
        <LiveFloorMap
          couriers={filtered}
          onMarkerClick={(driverId) => setSelectedDriverId(driverId)}
        />
      </div>
      {/* W5: XOR render — panel wins when a driver is selected; overlay otherwise.
          The mutual-exclusion guard at the setter level means BOTH cannot be
          truthy at once, so this ternary is guaranteed to render at most one. */}
      {selectedCourier ? (
        <CourierDetailPanel
          courier={selectedCourier}
          onClose={() => setSelectedDriverId(null)}
        />
      ) : listOpen ? (
        <FloorListOverlay
          couriers={filtered}
          status={filter.status ?? "WORKING"}
          onSelectDriver={(driverId) => setSelectedDriverId(driverId)}
          onClose={() => setListOpen(false)}
        />
      ) : null}
    </div>
  );
}

export default LiveFloorPage;

import type { FloorCounters, CourierStatus } from "@/types/floor";

// NIT1: All 3 pills built from a SINGLE array — one entry per FloorCounters key.
// Each entry carries an explicit status field (used for the active-pill highlight
// and propagated to onPillClick). The Order-rejection pill reuses STALE for its
// classification status because the map colour palette has no orange/rejection
// token; the dispatcher distinguishes the two via the list-overlay's filter label.
// The tooltip column documents the W3 known-limitation for the rejection pill.
interface PillSpec {
  key: keyof FloorCounters;
  status: CourierStatus;
  label: string;
  tooltip?: string;
}

const PILLS: PillSpec[] = [
  {
    key: "scheduledNotOnline",
    status: "SCHEDULED_NOT_ONLINE",
    label: "Scheduled-not-online",
  },
  {
    key: "gpsStale",
    status: "STALE",
    label: "GPS-stale",
  },
  {
    key: "orderRejection",
    // Reuses STALE for the marker classification (no separate colour token);
    // the list overlay shows the offending Keeta drivers by name so the
    // dispatcher sees the real signal regardless of the map colour.
    status: "STALE",
    label: "Order-rejection",
    // W3: documented v1 limitation on the user-facing tooltip.
    tooltip: "v1: Keeta only. Cross-platform signal ships in Phase 10.",
  },
];

export interface FloorPillCountersProps {
  counters: FloorCounters | undefined;
  activeStatus: CourierStatus | undefined;
  onPillClick: (status: CourierStatus) => void;
}

export function FloorPillCounters({ counters, activeStatus, onPillClick }: FloorPillCountersProps) {
  const c = counters ?? { scheduledNotOnline: 0, gpsStale: 0, orderRejection: 0 };
  return (
    <div className="flex items-center gap-2">
      {PILLS.map((p) => {
        const count = c[p.key];
        // Only the GPS-stale pill is "active" when activeStatus===STALE; the
        // Order-rejection pill shares the STALE status but is never the active
        // visual highlight (the dispatcher distinguishes them via the list
        // overlay's filter label).
        const isStaleSlot = p.key === "gpsStale";
        const active = p.status === activeStatus && (isStaleSlot || p.key === "scheduledNotOnline");
        const disabled = count === 0;
        return (
          <button
            key={p.key}
            type="button"
            aria-pressed={active}
            disabled={disabled}
            title={p.tooltip}
            onClick={() => onPillClick(p.status)}
            className={[
              "px-3 py-1.5 rounded-pill text-xs font-medium transition-colors duration-150",
              active ? "bg-primary text-white" : "bg-sand-100 text-sand-700 hover:bg-sand-200",
              disabled ? "opacity-50 cursor-not-allowed" : "",
            ].join(" ")}
            data-testid={`floor-pill-${p.key}`}
          >
            {p.label} <span className="ml-1 font-semibold">{count}</span>
          </button>
        );
      })}
    </div>
  );
}

export default FloorPillCounters;

"use client";
import { useEffect, useMemo, useRef, useState } from "react";
import { useRouter, useSearchParams, usePathname } from "next/navigation";
import { PLATFORM_BG } from "@/types/floor";
import type { CourierSnapshot, FloorFilter, Platform } from "@/types/floor";

const ALL_PLATFORMS: Platform[] = ["KEETA", "TALABAT", "DELIVEROO", "AMERICANA"];

export interface FloorFiltersProps {
  filter: FloorFilter;
  couriers: CourierSnapshot[];
  onChange: (next: FloorFilter) => void;
}

function buildUrl(pathname: string, filter: FloorFilter): string {
  const sp = new URLSearchParams();
  if (filter.status) sp.set("status", filter.status);
  if (filter.platforms && filter.platforms.length > 0) sp.set("platforms", filter.platforms.join(","));
  if (filter.area) sp.set("area", filter.area);
  if (filter.q) sp.set("q", filter.q);
  const qs = sp.toString();
  return qs ? `${pathname}?${qs}` : pathname;
}

export function FloorFilters({ filter, couriers, onChange }: FloorFiltersProps) {
  const router = useRouter();
  const pathname = usePathname();
  const searchParams = useSearchParams();

  // Sync filter changes to URLSearchParams (router.replace = no history pollution).
  useEffect(() => {
    const next = buildUrl(pathname ?? "/floor", filter);
    const current = `${pathname}${searchParams?.toString() ? "?" + searchParams.toString() : ""}`;
    if (next !== current) {
      router.replace(next, { scroll: false });
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [filter, pathname]);

  const togglePlatform = (p: Platform) => {
    const current = filter.platforms ?? [];
    const next = current.includes(p) ? current.filter((x) => x !== p) : [...current, p];
    onChange({ ...filter, platforms: next.length > 0 ? next : undefined });
  };

  const areas = useMemo(() => {
    const set = new Set<string>();
    for (const c of couriers) if (c.area) set.add(c.area);
    return Array.from(set).sort();
  }, [couriers]);

  // Debounced search.
  const [qLocal, setQLocal] = useState(filter.q ?? "");
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
  useEffect(() => { setQLocal(filter.q ?? ""); }, [filter.q]);
  const onSearchInput = (e: React.ChangeEvent<HTMLInputElement>) => {
    const v = e.target.value;
    setQLocal(v);
    if (timerRef.current) clearTimeout(timerRef.current);
    timerRef.current = setTimeout(() => {
      onChange({ ...filter, q: v.trim() || undefined });
    }, 200);
  };
  useEffect(() => () => { if (timerRef.current) clearTimeout(timerRef.current); }, []);

  return (
    <div className="border-b border-sand-200 px-6 py-2 flex items-center gap-3 bg-card">
      <div className="flex items-center gap-1.5">
        {ALL_PLATFORMS.map((p) => {
          const active = (filter.platforms ?? []).includes(p);
          // B3: static map lookup — Tailwind JIT sees bg-keeta/bg-talabat/etc. in types/floor.ts source.
          const activeBg = PLATFORM_BG[p];
          return (
            <button
              key={p}
              type="button"
              onClick={() => togglePlatform(p)}
              aria-pressed={active}
              className={[
                "px-2.5 py-1 rounded-pill text-[11px] font-medium transition-colors",
                active ? `${activeBg} text-white` : "bg-sand-100 text-sand-700",
              ].join(" ")}
              data-testid={`floor-platform-${p}`}
            >
              {p}
            </button>
          );
        })}
      </div>
      <select
        value={filter.area ?? ""}
        onChange={(e) => onChange({ ...filter, area: e.target.value || undefined })}
        className="px-2 py-1 text-xs rounded-pill bg-sand-100 border-0"
        data-testid="floor-area-select"
      >
        <option value="">All areas</option>
        {areas.map((a) => (<option key={a} value={a}>{a}</option>))}
      </select>
      <input
        type="search"
        placeholder="Search name or phone…"
        value={qLocal}
        onChange={onSearchInput}
        className="px-2 py-1 text-xs rounded-pill bg-sand-100 border-0 flex-1 max-w-xs"
        data-testid="floor-search-input"
      />
      {filter.status && (
        <button
          type="button"
          onClick={() => onChange({ ...filter, status: undefined })}
          className="text-[11px] text-sand-600 hover:text-sand-900 underline"
          data-testid="floor-clear-status"
        >
          Clear status filter
        </button>
      )}
    </div>
  );
}

export default FloorFilters;

import { useState } from "react";
import { Send } from "lucide-react";
import api from "@/lib/api";
import { ChatActionCard } from "@/components/chat/ChatActionCard";
import type { CourierSnapshot, PingIntent } from "@/types/floor";

// Phase 7 — reuses Phase 2 propose-and-confirm via Wave 1's /api/floor/ping/:driverId.
// Phase 9 will swap this body wiring to bilingual + real WhatsApp delivery; v1 stages
// an IN_APP/notification draft per Pattern 5 + resolution #3.

function draftBody(courier: CourierSnapshot, intent: PingIntent): string {
  const name = courier.name.split(" ")[0] ?? courier.name;
  switch (intent) {
    case "WARN_GPS_STALE":
      return `Hi ${name}, your GPS hasn't updated in 15+ minutes. Could you check your app is open and location permissions are granted? Thanks — Darb`;
    case "WARN_ORDER_REJECTIONS":
      return `Hi ${name}, we noticed multiple order rejections today. Is everything okay with your assignments? Let's chat. — Darb`;
    case "WARN_LATE_CLOCKIN":
      return `Hi ${name}, your shift started but you haven't clocked in yet. Please clock in or let us know if you're delayed. — Darb`;
  }
}

export interface PingButtonProps {
  courier: CourierSnapshot;
  intent: PingIntent;
}

type ButtonState =
  | { kind: "idle" }
  | { kind: "submitting" }
  | { kind: "staged"; pendingActionId: string; body: string }
  | { kind: "error"; message: string };

export function PingButton({ courier, intent }: PingButtonProps) {
  const [state, setState] = useState<ButtonState>({ kind: "idle" });
  const body = draftBody(courier, intent);

  const handleSubmit = async () => {
    setState({ kind: "submitting" });
    try {
      const res = await api.post(`/api/floor/ping/${courier.driverId}`, {
        intent,
        bodyEnglish: body,
        channel: "WHATSAPP",
      });
      const pid = res.data?.pendingActionId;
      if (!pid) {
        setState({ kind: "error", message: "Unexpected server response" });
        return;
      }
      setState({ kind: "staged", pendingActionId: pid, body });
    } catch (err: any) {
      const status = err?.response?.status;
      const msg = status === 404
        ? "Driver not found in tenant scope"
        : status === 400
          ? "Invalid ping intent or body"
          : (err?.response?.data?.error ?? err?.message ?? "Failed to stage ping");
      setState({ kind: "error", message: msg });
    }
  };

  if (state.kind === "staged") {
    return (
      <ChatActionCard
        proposal={{
          pendingActionId: state.pendingActionId,
          subject: `Ping ${courier.name}`,
          body: state.body,
          ctaLabel: "Send via Darb",
          toolName: "draftCourierMessage",
        }}
        onDismiss={() => setState({ kind: "idle" })}
      />
    );
  }

  return (
    <div className="space-y-2" data-testid="ping-button-wrapper">
      <div className="text-[11px] uppercase tracking-widest text-sand-600">Suggested message</div>
      <div className="bg-sand-50 border border-sand-200 rounded-md px-3 py-2 text-xs text-sand-700 whitespace-pre-wrap">
        {body}
      </div>
      {state.kind === "error" && (
        <div className="text-xs text-red-600">{state.message}</div>
      )}
      <button
        type="button"
        onClick={handleSubmit}
        disabled={state.kind === "submitting"}
        className="inline-flex items-center gap-1.5 px-3 py-1.5 rounded-pill bg-primary text-white text-xs font-medium hover:bg-primary/90 disabled:opacity-50"
        data-testid="ping-button-submit"
      >
        <Send size={14} />
        {state.kind === "submitting" ? "Staging…" : "Send via Darb"}
      </button>
      <p className="text-[10px] text-sand-500">Real WhatsApp delivery wires up in Phase 9.</p>
    </div>
  );
}

export default PingButton;

  }, [courier.driverId]);

  const recent = (file?.recentOrderEvents ?? []).slice(0, 5);

    cached: false,

    <SlidePanel
      open={true}
      onClose={onClose}
      title={courier.name}
      subtitle={courier.platform ?? "Driver"}

            name={<span className="text-sm">Open Driver File →</span>}
            platform={(courier.platform?.toLowerCase() as any) ?? undefined}
            className="text-primary text-sm hover:underline"

              {courier.platform}

        {/* Score chip — small variant of Phase 3's score visual */}
        {score != null && (
          <div className="flex items-baseline gap-2">
            <span className="text-[11px] uppercase tracking-widest text-sand-600">Score</span>
            <span className="font-display text-display-sm text-sand-900">{score.value}</span>

              <span className={`text-xs ${score.delta >= 0 ? "text-emerald-600" : "text-red-600"}`}>
                {score.delta >= 0 ? "+" : ""}{score.delta}
              </span>
            )}
